## Claims I could not verify, and why

1. FFmpeg `-protocol_whitelist` semantics, HLS/concat behaviour (F-17): ffmpeg.org protocols page fetch returned empty; Black Hat PDF not opened. Recommend a local test with the pinned FFmpeg build.
2. Pexels video-search `orientation` param and `video_files` fields (F-20): Pexels docs sit behind a Cloudflare challenge.
3. R2 presigned PUT enforcing `Content-Length` / POST policy `content-length-range` (F-25): not documented on Cloudflare's pages; needs a spike (already Q-02).
4. "~8 % SMC octave errors" (F-04): no source located.
5. Platform loudness for TikTok/Instagram (F-34): no official spec found; docs already say unverified.
6. Pixabay video response field names and absence of an orientation filter (F-23): not confirmed in extracted text.
7. FFmpeg fix versions for CVE-2025-9951 (F-13): NVD record carries no version ranges.
8. TransNetV2 weights licence (F-37): code licence MIT confirmed; weights terms not checked.
9. Direct benchmark TransNetV2 vs PySceneDetect on full ClipShots under one protocol (F-38): no such head-to-head found.
10. GDPR Art. 33 and WCAG 2.3.1 wording (F-28, F-33): stated from the legal/spec text, not freshly extracted.
11. Alembic version, Stripe webhook details, Next.js CSP, Dokploy items: out of scope for this pass.
