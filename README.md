# SaveClock Studio

Turns a song into a beat-synced vertical (9:16) video made from stock clips. Every cut lands exactly on a beat or downbeat. You can then fine-tune the cuts and export the video, either with the original song or silent, with a cut list.

**Status:** Phase 0 (validation spike) is in progress. There is no app code yet.

- `docs/` — product, architecture, quality, security and design docs. `docs/DECISIONS.md` is the source of truth.
- `plans/` — the execution plan for each phase.
- `spike/` — the Phase 0 test harness and its results.
- `docs/mockups/index.html` — clickable screen mockups.
- `docs/SETUP.md` — set up and test the app on another PC after cloning.

It is a personal, local-only app (DECISIONS Rev 3.5). No license has been granted yet, so all rights are reserved.
